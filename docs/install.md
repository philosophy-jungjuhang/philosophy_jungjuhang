# 앱으로 설치하기

<p class="ep-meta"><span>안내</span><span>읽는 시간 약 2분</span><span>2026-11-17</span></p>

철학 정주행은 앱 가게(앱스토어, 플레이 스토어)를 거치지 않고 **브라우저에서 바로 앱처럼 설치**할 수 있어요. 설치하면 이렇게 돼요.

- 홈 화면이나 바탕화면에 올빼미 아이콘이 생기고, 주소창 없이 책만 꽉 차게 보여요.
- 한 번 열어 본 페이지는 **인터넷이 없어도** 다시 읽을 수 있어요.
- 설치 파일을 따로 받지 않아요. 지우고 싶으면 다른 앱처럼 아이콘을 길게 눌러 지우면 돼요.

<p class="pj-status"></p>

[지금 설치하기](#guides){ .md-button .md-button--primary data-install="1" }

버튼을 눌러도 설치 창이 뜨지 않으면, 아래에서 쓰는 브라우저의 방법을 따라 하세요. 지금 쓰는 브라우저의 방법이 맨 위에 와요.

<div class="pj-guides" id="guides" markdown>

<div class="pj-guide" data-guide="android-chrome" markdown>
### 안드로이드 · 크롬, 엣지

1. 위의 **지금 설치하기** 버튼을 누르고 **설치**를 눌러요.
2. 창이 뜨지 않으면 오른쪽 위 **⋮** 메뉴를 열고 **앱 설치** 또는 **홈 화면에 추가**를 눌러요.
</div>

<div class="pj-guide" data-guide="samsung" markdown>
### 안드로이드 · 삼성 인터넷

1. 주소창에 설치 아이콘(아래 화살표)이 보이면 눌러요.
2. 없으면 아래쪽 **≡** 메뉴 → **현재 페이지 추가** → **홈 화면**을 눌러요.
</div>

<div class="pj-guide" data-guide="ios" markdown>
### 아이폰, 아이패드 · 사파리 (크롬, 엣지도 같아요)

1. **공유** 버튼(네모에서 위로 나가는 화살표)을 눌러요. 안 보이면 주소창 옆 **⋯** 를 먼저 눌러요.
2. 목록을 내려 **홈 화면에 추가**를 눌러요.
3. 오른쪽 위 **추가**를 누르면 홈 화면에 올빼미가 생겨요.
</div>

<div class="pj-guide" data-guide="android-firefox" markdown>
### 안드로이드 · 파이어폭스

1. 오른쪽 위(또는 아래) **⋮** 메뉴를 열어요.
2. **설치** 또는 **홈 화면에 추가**를 눌러요.
</div>

<div class="pj-guide" data-guide="desktop-chromium" markdown>
### 컴퓨터 · 크롬, 엣지, 웨일

1. 위의 **지금 설치하기** 버튼을 누르고 **설치**를 눌러요.
2. 창이 뜨지 않으면 주소창 오른쪽 끝의 설치 아이콘(화면에 아래 화살표)을 눌러요.
3. 그래도 없으면 오른쪽 위 메뉴(**⋮** 또는 **⋯**)에서 "설치" 또는 "앱"이 들어간 항목을 찾아 눌러요.
</div>

<div class="pj-guide" data-guide="mac-safari" markdown>
### 맥 · 사파리 (macOS 소노마 이후)

1. 위쪽 메뉴 막대에서 **파일** → **Dock에 추가**를 눌러요.
2. **추가**를 누르면 Dock에 올빼미가 생겨요.
</div>

<div class="pj-guide" data-guide="desktop-firefox" markdown>
### 컴퓨터 · 파이어폭스

파이어폭스 데스크톱은 아직 앱 설치를 기본으로 지원하지 않아요. 크롬이나 엣지로 이 페이지를 열어 설치하거나, 즐겨찾기(Ctrl+D, 맥은 ⌘+D)에 추가해 두세요.
</div>

</div>

## 인터넷 없이 책 전체 읽기

설치하면 열어 본 페이지만 저장돼요. 비행기나 지하철에서 읽으려면 아래 버튼을 한 번 눌러 모든 페이지(부·장 안내까지 약 150쪽)를 받아 두세요. 와이파이에서 누르는 걸 추천해요(약 20MB).

[책 전체 저장하기](#guides){ .md-button data-save-all="1" }

<p class="pj-save-status"></p>

!!! note "알아 두면 좋은 것"
    - 새 글이나 고친 글은 인터넷에 연결된 상태에서 앱을 열면 저절로 받아져요.
    - 브라우저의 "인터넷 사용 기록 삭제"에서 사이트 데이터를 지우면 저장해 둔 페이지도 지워져요.
    - 메뉴 이름은 2026년 11월 기준이에요. 브라우저가 업데이트되면 이름이 조금 바뀔 수 있어요.
