# 2500년 동안 사람들이 던진 질문을 따라가는 책

"나는 누구지?", "착하게 살아야 하는 이유는 뭘까?" 이런 질문을 해 봤다면 이미 철학을 시작한 거예요.
소크라테스부터 공자, 이븐 시나, 퇴계, 보부아르까지, 누가 무엇을 묻고 어떻게 답했는지 쉬운 말로 따라가요.

## 이 책으로 할 수 있는 것

<ul class="gains">
<li><b>유명한 말의 진짜 뜻을 알아요</b><span>"신은 죽었다", "나는 생각한다, 그러므로 나는 있다"가 원래 어떤 맥락에서 나왔는지 봐요</span></li>
<li><b>동쪽과 서쪽을 함께 봐요</b><span>같은 시대에 그리스, 중국, 인도, 이슬람 세계, 조선이 같은 질문에 다르게 답했어요</span></li>
